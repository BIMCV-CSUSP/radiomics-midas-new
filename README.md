# Machine Learning Classification: Pfirrmann Disc Degeneration (Phase 2)
This branch contains the updated machine learning pipeline and results for the automated classification of lumbar intervertebral disc degeneration. Compared to previous iterations, this version features an expanded and more balanced dataset, including a wider range of patients with Pfirrmann grades 1 through 5.

# Dataset Overview
- Expanded Patient Cohort: This phase incorporates a significantly larger number of patient records compared to the initial trials.

- Improved Class Balance: The dataset has been specifically curated to include representative samples across the full spectrum of Pfirrmann degeneration grades (1 to 5), leading to more robust model generalization.

- Data Quality: All images have been processed through the standardized segmentation and feature extraction pipeline (refer to the radiomics_extraction branch for details).

# Modeling Pipeline
The pipeline follows a rigorous data-science approach to ensure reproducibility and statistical validity:

- Data Preprocessing: Features are cleaned and filtered to prevent data leakage, ensuring no patient-level information is shared between training and validation sets.

- Feature Selection: Statistical analysis (Shapiro-Wilk for normality, T-test or Mann-Whitney U for distribution comparison) is performed to retain only the most discriminant radiomic features.

- Model Training: We utilize StratifiedGroupKFold cross-validation to maintain patient-level separation and ensure consistent class distributions across folds.

- Model Comparison: We employ the Friedman Test for global comparison and the Wilcoxon test with Holm correction for post-hoc analysis to confirm if performance differences between classifiers are statistically significant.

# Model Interpretability and Optimization
To move beyond a "black box" approach, this phase includes advanced refinement:

- Bayesian Optimization: We use BayesSearchCV to intelligently fine-tune hyperparameters, replacing traditional grid-search methods for better computational efficiency.

- Probability Calibration: We apply Platt scaling (sigmoid method) to ensure model output probabilities are clinically reliable.

# Results Structure
The output generated by this pipeline is organized into:

- results.csv: Comprehensive performance metrics per fold and per repeat.

- predictions.csv: Raw prediction and probability data.

- best_results/: Contains the fine-tuned model, calibration plots, and interpretability reports (SHAP/LIME).

- model_differences/: Contains the statistical summary comparing all evaluated classifiers.

# Execution 
python train_binary.py \
  --csv /path/to/your/merged_features.csv \
  --results_base /path/to/your/new/run \
  or 
python train_binary.py \
  --csv /path/to/your/merged_features.csv \
  --resume_run /path/to/your/old/run \

- --csv (Required): Path to the input CSV file containing radiomic features, labels, and patient identifiers.

- --results_base: The root directory where all experiment folders (run_...) are stored (default: /mnt/datalake/.../binary_new).

- --n_splits: Number of folds for the Stratified Group K-Fold cross-validation (default: 5).

- --n_repeats: Number of cross-validation repetitions to ensure statistical robustness (default: 10).

- --resume_run: Path to a previous run_... directory. If provided, the pipeline attempts to load existing results.csv and predictions.csv files instead of re-training models.


SHAP Analysis: We generate SHAP (SHapley Additive exPlanations) values to interpret how specific radiomic features influence individual Pfirrmann grade predictions.

SHAP Statistical Validation: We apply the Mann-Whitney U test with Holm correction to SHAP values to statistically validate which features truly drive the model's decision-making process.
